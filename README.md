# x-clean-link
Strips tracking parameters from X/Twitter links on copy on X.com
![Screenshot](assets/media/screenshot1.png)

Chrome web store: [x-clean-link chrome extension](https://chromewebstore.google.com/detail/x-clean-link/mbilgoihchhlkpjlmpbmlodeedfpfaem)

Offline install:
1. Download [Download x-clean-link_v1.zip](x-clean-link_v1.zip)
2. Extract into a folder
3. Open chrome://extensions and toggle on Developer mode
4. Click Load unpacked, and select the folder
